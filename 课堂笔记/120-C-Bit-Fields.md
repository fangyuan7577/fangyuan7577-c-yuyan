> 第119集的 `1u << n` 技巧只能控制**一个比特**。位段把 `int` 的若干位组合成一个**结构体**，用成员名直接访问多个比特，比“移位 + 与/或”更方便[reference:0]。

## 二、语法与内存布局

```c
struct {
    unsigned int leading  : 3;   // 占低3位
    unsigned int trailing : 5;   // 占接着的5位
} uu;
```

| 关键规则 | 说明 |
| :--- | :--- |
| **冒号后的数字** | 该成员占用的**比特数** |
| **总位数超过一个 int** | 编译器自动安排**多个 int**（`sizeof` 从 4 变为 8）[reference:1] |
| **成员访问** | 直接使用 `uu.trailing`，无需手动移位和掩码[reference:2] |

## 三、核心限制：不可移植

| 问题 | 说明 |
| :--- | :--- |
| **位排列顺序由编译器决定** | 有的从最右边排起，有的从最左边，**不同编译器布局不同**[reference:3] |
| **跨平台不可靠** | 位段是**硬件相关的底层操作**，不适合需要跨平台兼容的数据交换 |
| **本质** | 位段是对第119集“构造掩码 + 位运算”的**语法封装**，底层仍然是按位操作 |

> **结论**：位段适合**本地硬件寄存器操作**，不适合作为可移植的数据存储格式[reference:4]。
