# 【翁恺C语言】第123集：14.1.3 可变数组的自动增长

## 一、自动增长（Inflate）原理
当访问的索引超出当前 `size` 时，触发增长机制。

| 步骤 | 操作 | 说明 |
| :--- | :--- | :--- |
| 1 | `malloc` 新空间 | 申请一块更大的内存（如按固定 block_size 成倍增长） |
| 2 | `memcpy` 拷贝数据 | 将旧空间的数据原样拷贝到新空间 |
| 3 | `free` 旧空间 | 释放原来的内存，防止内存泄漏 |
| 4 | 更新 `array` 指针 | 让 `a->array` 指向新空间 |

## 二、增长策略
| 策略 | 优点 | 缺点 |
| :--- | :--- | :--- |
| **按需 +1** | 不浪费空间 | 每次都要重新分配、拷贝，效率极低 |
| **按块增长 (Block)** | 减少拷贝次数 | 会预留一些暂时用不到的空间 |
