## 二、左移运算 `<<`

左移将操作数的二进制位整体向左移动，**右边空出的位一律补 0**，左边移出的位被丢弃。

| 规则 | 说明 |
| :--- | :--- |
| **等价运算** | `x << 1` 等价于 `x * 2`；`x << n` 等价于 `x * 2^n`（前提是不溢出） |
| **类型提升** | 所有小于`int`的类型（如`char`、`short`），移位时**先被提升为`int`**，结果也是`int` |
| **移位位数上限** | 最多可移动的位数**取决于`int`的大小**（通常是31位，移位32位是未定义行为） |
| **符号位风险** | 有符号数左移时，**符号位会被无情挤掉**，如果正数变成了负数，属于未定义行为（C标准未定义） |

## 三、右移运算 `>>`

右移将二进制位整体向右移动，但**空出的高位如何填充，取决于操作数的类型**。

| 类型 | 右移规则 | 高位填充 | 别名 |
| :--- | :--- | :--- | :--- |
| **`unsigned`**（无符号） | **逻辑右移** | **一律补 0** | Logical Shift |
| **`signed`**（有符号） | **算术右移**（通常） | **补原来的最高位**（符号位），保持符号不变 | Arithmetic Shift |

> **关键点**：C 标准**未规定**有符号数右移必须采用算术右移，这属于**实现定义行为**。但主流编译器（GCC、Clang、MSVC）均采用算术右移。

### 右移与除法

| 表达式 | 等价运算 | 注意事项 |
| :--- | :--- | :--- |
| `x >> 1` | `x / 2` | 对**正数**成立 |
| `x >> n` | `x / 2^n` | 对**正数**成立 |
| `-5 >> 1` | 结果通常为 `-3`（算术右移） | 与 `-5 / 2`（结果为 `-2`，向零取整）**不等价** |

## 四、关键陷阱与未定义行为

| 陷阱 | 说明 |
| :--- | :--- |
| **移位位数为负数** | `x << -2` 是**未定义行为**，程序可能直接崩溃或产生乱码 |
| **移位位数 ≥ 类型宽度** | 对32位`int`移位32位或更多是**未定义行为**，移位位数应始终 `< 32` |
| **有符号左移改变符号位** | 比如 `1 << 31`，原本是正数，移完后变成了负数，属于**未定义行为**，必须用 `1u << 31` |
| **有符号右移依赖实现** | 负数右移的结果**依赖编译器**，在要求严格可移植性的代码中不应依赖这一行为 |

## 五、代码示例：观察类型提升与移位

```c
#include <stdio.h>

int main(void) {
    unsigned char c = 0xA5;          // 8位无符号
    printf("c     = %hhx\n", c);
    printf("c<<2  = %hhx\n", c << 2); // 先提升为int再左移，结果仍为int
    printf("sizeof(c<<2) = %zu\n", sizeof(c << 2)); // 通常是4（int大小）

    int a = -5;
    printf("a>>1  = %d\n", a >> 1);  // 算术右移，通常为 -3

    unsigned int ua = 0xFFFFFFFBu;   // -5 的无符号表示
    printf("ua>>1 = %u\n", ua >> 1); // 逻辑右移，高位补0
    return 0;
}
```

## 六、移位运算的典型应用

| 场景 | 用法 |
| :--- | :--- |
| **快速乘除 2 的幂** | `x << n` 替代 `x * (1 << n)`；`x >> n` 替代 `x / (1 << n)`（需确保正数且不溢出） |
| **构造掩码** | `1u << n` 生成只有第 `n` 位为 1 的掩码，配合 `&`、`\|` 使用 |
| **提取/组合位字段** | 通过 `&` 与 `>>` 从打包数据中提取特定位，或反向组合 |
| **纯二进制运算** | `unsigned` 类型的核心用途之一就是进行**无符号位歧义的移位运算** |
