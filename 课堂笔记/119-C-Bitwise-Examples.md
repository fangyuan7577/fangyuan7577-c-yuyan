## 二、位运算的典型用途

| 用途 | 说明 |
| :--- | :--- |
| **输出一个数字的二进制** | 用掩码（mask）逐位与目标数进行按位与，判断每一位是 0 还是 1 |
| **操作硬件寄存器（SFR）** | 单片机开发中，用按位或置位、按位与+取反清零，精确控制寄存器特定位 |

## 三、示例1：输出一个数的二进制

### 核心思路

从最高位开始，用一个只有当前位为 `1`、其余全为 `0` 的掩码去和 `number` 做 `&` 运算。结果非 `0` 说明该位是 `1`，结果为 `0` 说明该位是 `0`[reference:2]。

### 代码实现

```c
#include <stdio.h>

int main(void) {
    int number;
    scanf("%d", &number);

    unsigned mask = 1u << 31;   // 从最高位（第31位）开始
    for (; mask; mask >>= 1) {  // mask 每次右移1位，直到变为0
        printf("%d", (number & mask) ? 1 : 0);
    }
    printf("\n");
    return 0;
}
```

### 关键点解读

| 要点 | 说明 |
| :--- | :--- |
| **`unsigned mask`** | `unsigned` 后面不跟类型时默认为 `unsigned int`[reference:3] |
| **`1u << 31`** | `u` 确保 `1` 是 `unsigned int`，避免有符号左移的未定义行为 |
| **`mask >>= 1`** | 无符号右移，高位补 0；循环直到 `mask` 变为 `0` 自动结束 |
| **`number & mask`** | 掩码只保留当前位，其余位被清零；结果非 0 即该位为 1 |

## 四、示例2：单片机 SFR 的位操作

在单片机开发中，经常需要对特殊功能寄存器（SFR）的**特定比特**进行置 1 或清 0[reference:4]。

### 核心口诀

| 操作 | 方法 | 说明 |
| :--- | :--- | :--- |
| **将某一位置 1** | `x \|= (1u << n)` | 按位或，第 n 位变为 1 |
| **将某一位清 0** | `x &= ~(1u << n)` | 按位与 + 取反，第 n 位变为 0 |
| **同时操作多位** | 先用 `\|` 组合掩码，再操作 | 例如 `SBS \| PE` |

### 代码示例

```c
const unsigned int SBS = 1u << 2;   // 第2位
const unsigned int PE  = 1u << 3;   // 第3位

U0LCR |= SBS | PE;          // 将第2位和第3位 置1（按位或）
U0LCR &= ~SBS;              // 将第2位 清零（按位与 + 取反）
U0LCR &= ~(SBS | PE);       // 将第2位和第3位 同时清零
```

> `1u << n` 就是构造“第 n 位为 1，其余全 0”的掩码；`~` 取反后得到“第 n 位为 0，其余全 1”的掩码[reference:5]。
