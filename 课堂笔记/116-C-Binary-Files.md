## 二、核心知识点：二进制文件
| 知识点分类 | 关键函数/概念 | 详细说明 |
| :--- | :--- | :--- |
| **模式对比** | 文本文件 vs 二进制文件 | 二进制模式 (`rb`, `wb`) 原样读写内存数据，不进行编码转换，适合存储结构体、数组。 |
| **核心读写** | `fread()` / `fwrite()` | 高效读写二进制数据块。直接将内存中的一块数据原样写入文件，或读回内存。 |
| **文件定位** | `fseek()` / `ftell()` | 在二进制文件中自由移动读写指针，实现**随机访问**。 |

## 三、按位运算基础（原版分析）
| 运算符 | 名称 | 功能简述 |
| :--- | :--- | :--- |
| `&` | 按位与 | 同1才1，常用于清零、取位 |
| `\|` | 按位或 | 有1则1，常用于将特定位置1 |
| `~` | 按位取反 | 0变1，1变0 |
| `^` | 按位异或 | 相同为0，不同为1，用于加密或交换两数 |
