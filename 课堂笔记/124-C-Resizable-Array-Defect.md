# 【翁恺C语言】第124集：14.2.1 可变数组的缺陷

## 一、可变数组的致命弱点
| 缺陷 | 详细说明 |
| :--- | :--- |
| **增长代价大** | 需要**重新申请内存**、**拷贝所有旧数据**、**释放旧内存**。如果数组很大，这个过程非常耗时。 |
| **内存碎片** | 不断申请更大的内存，可能会导致原本的空间被废弃，产生内存碎片。 |

## 二、引子：如何解决？
> **如果我不要求数据在内存中是连续存放的呢？**
> 这就引出了下一章的核心数据结构：**链表 (Linked List)**。链表通过指针把零散的内存块串联起来，插入和删除时不需要大规模拷贝。
