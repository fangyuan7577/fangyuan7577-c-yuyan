## 二、六种位运算符一览

C语言提供以下6种位运算符，**操作数必须是整型（含 `char`）**，不能是浮点数：

| 运算符 | 名称 | 功能简述 |
| :--- | :--- | :--- |
| `&` | 按位与 | 两位**同为1**时结果为1，否则为0 |
| `\|` | 按位或 | 两位**至少一个为1**时结果为1 |
| `~` | 按位取反 | 单目运算符，**0变1，1变0** |
| `^` | 按位异或 | 两位**不同**时结果为1，相同为0 |
| `<<` | 左移 | 所有位向左移动，右边补0（第118集详讲） |
| `>>` | 右移 | 所有位向右移动，符号位处理见第118集 |

## 三、核心辨析：按位运算 vs 逻辑运算

这是本集最关键的概念区分。翁恺老师用具体数值展示了二者的天壤之别：

| 表达式 | 运算类型 | 计算过程 | 结果 | 关键说明 |
| :--- | :--- | :--- | :--- | :--- |
| `5 & 4` | **按位与** | `0101 & 0100` → `0100` | **4** | 按二进制位逐位运算 |
| `5 && 4` | **逻辑与** | 两者均非0 → 视为 `1 && 1` | **1** | 只关心“真/假”（非0即真） |
| `5 \| 4` | **按位或** | `0101 \| 0100` → `0101` | **5** | 保留所有为1的位 |
| `5 \|\| 4` | **逻辑或** | 两者均非0 → 视为 `1 \|\| 1` | **1** | 结果只有0或1 |
| `~4` | **按位取反** | 对 `...00000100` 逐位取反 | **-5**（补码表示） | 对所有位操作，不只是最低位 |
| `!4` | **逻辑非** | 4为真 → `!1` | **0** | 仅翻转真/假值 |

> **一句话总结**：逻辑运算先把所有非0值“压缩”成1，再按位算；按位运算则直接对每一个二进制位动手。

## 四、按位与（`&`）的经典用途

按位与的核心口诀是 **“同1才1”**，常用于**清零**或**取位**：

| 用途 | 操作方式 | 说明 |
| :--- | :--- | :--- |
| **将某一位置0** | `x & ~(1u << n)` | 构造一个第n位为0、其余全1的掩码，与`x`相与 |
| **判断某一位是否为1** | `if (x & (1u << n))` | 掩码只保留第n位，结果非0即表示该位为1 |
| **取一个数的低n位** | `x & ((1u << n) - 1)` | 掩码的低n位全1，高位全0 |

## 五、按位或（`\|`）与异或（`^`）的用途

| 运算符 | 经典用途 | 示例 |
| :--- | :--- | :--- |
| **按位或 `\|`** | **将某一位置1** | `x \|= (1u << n)` |
| **按位异或 `^`** | **翻转某一位**（1变0，0变1） | `x ^= (1u << n)` |
| **按位异或 `^`** | **不使用临时变量交换两数** | `a ^= b; b ^= a; a ^= b;` |

### 补充：异或交换两个变量的原理
```c
int a = 5, b = 3;
a = a ^ b;  // a 变成了 5^3
b = a ^ b;  // b 变成了 (5^3)^3 = 5
a = a ^ b;  // a 变成了 (5^3)^5 = 3
// 结果：a 变成 3，b 变成 5
```

## 六、代码示例：输出一个整数的二进制表示

利用“按位与 + 移位”逐位检查，是理解位运算的经典练习：

```c
#include <stdio.h>

int main(void) {
    int number;
    scanf("%d", &number);

    unsigned mask = 1u << 31;   // 从最高位（第31位）开始检查
    for (; mask; mask >>= 1) {  // mask 每次右移1位，直到变为0
        printf("%d", (number & mask) ? 1 : 0);
    }
    printf("\n");
    return 0;
}
```

> `1u << 31` 中的 `u` 确保 `1` 被当作 `unsigned int` 处理，避免有符号左移的未定义行为。

## 七、硬件编程中的位操作模式（SFR）

在单片机等嵌入式场景中，常需要对**特殊功能寄存器（SFR）**的特定比特进行置位或清零：

```c
const unsigned int SBS = 1u << 2;   // 第2位
const unsigned int PE  = 1u << 3;   // 第3位

U0LCR |= SBS | PE;          // 将第2位和第3位 置1（按位或）
U0LCR &= ~SBS;              // 将第2位 清零（按位与 + 取反）
U0LCR &= ~(SBS | PE);       // 将第2位和第3位 同时清零
```
