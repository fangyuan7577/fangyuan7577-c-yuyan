# 【翁恺C语言】第121集：14.1.1 可变数组

## 一、为什么需要可变数组
| 问题 | 说明 |
| :--- | :--- |
| **定长数组的局限** | 大小固定，无法在运行中动态伸缩 |
| **目标** | 实现一个能**自动增长**、能获取当前大小、能访问单元的数组 |

## 二、核心结构体设计
```c
typedef struct {
    int *array;  // 指向实际分配的连续内存
    int size;    // 当前数组的容量
} Array;
```

| 要点 | 说明 |
| :--- | :--- |
| **`int *array`** | 用指针指向动态分配的内存（`malloc`） |
| **`int size`** | 记录当前容量，用于判断是否需要增长 |
