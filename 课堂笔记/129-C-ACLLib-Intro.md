## 三、ACLLib 的基本用法（极简版）
1. 引入头文件 `#include "acllib.h"`
2. 编写 `Setup()` 函数（代替 `main`）
3. 调用 `initWindow()` 创建窗口
4. 在 `beginPaint()` 和 `endPaint()` 之间绘图

```c
#include "acllib.h"

int Setup() {
    initWindow("My First Window", 100, 100, 400, 400);
    beginPaint();
    line(0, 0, 200, 200); // 画条线
    endPaint();
    return 0;
}
```
