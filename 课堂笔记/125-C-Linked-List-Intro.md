# 【翁恺C语言】第125集：14.2.2 链表

## 一、链表的基本结构
```c
typedef struct _node {
    int value;           // 数据域
    struct _node *next;  // 指针域，指向下一个结点
} Node;
```

| 概念 | 说明 |
| :--- | :--- |
| **Head（头指针）** | 指向链表第一个结点的指针。如果链表为空，`head == NULL`。 |
| **结点（Node）** | 包含数据和下一个结点地址的结构体。 |
| **尾结点** | 最后一个结点，其 `next` 指针必须为 `NULL`。 |

## 二、创建第一个结点
| 步骤 | 代码示例 |
| :--- | :--- |
| 分配内存 | `Node *p = (Node*)malloc(sizeof(Node));` |
| 填入数据 | `p->value = 10;` |
| 初始化指针 | `p->next = NULL;`（**非常关键，防野指针**） |
| 挂上链表 | `head = p;` |
