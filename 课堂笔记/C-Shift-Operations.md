## 二、左移运算 `<<`

### 基本规则

左移运算将操作数的二进制位**整体向左移动**指定的位数：

- **高位（左边）移出的位被丢弃**
- **低位（右边）空出的位置一律补 0**[reference:1]

```c
int a = 5;      // 二进制：00000000 00000000 00000000 00000101
int b = a << 1; // 二进制：00000000 00000000 00000000 00001010 → 10
